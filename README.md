# 📖 Overview

This repository contains implementations of essential **Data Structures** concepts that are commonly used in computer science and software engineering.

The project focuses on:

- Implementing a **Graph** data structure.
- Traversing graphs using **Depth-First Search (DFS)**.
- Building a **Queue** from scratch.
- Demonstrating queue operations through a simple web interface.

The project is intended for educational purposes and serves as a practical introduction to these fundamental algorithms and data structures.

# 📚 Concepts Covered

## Graph

The project implements a graph structure capable of representing relationships between connected nodes.

### Operations

- Add Vertex
- Add Edge
- Store adjacency relationships

---

## Depth-First Search (DFS)

DFS is implemented to explore graph nodes recursively or iteratively.

### Characteristics

- Traverses one branch completely before backtracking
- Uses recursion or stack
- Time Complexity: **O(V + E)**

---

## Queue

The Queue follows the **FIFO (First In, First Out)** principle.

### Supported Operations

- Enqueue
- Dequeue
- Peek
- Check Empty
- Display Queue
